
# Campus Sustainability Assistant

A web-based chatbot prototype developed during the 1M1B AI for Sustainability Virtual Internship.

The application promotes sustainable campus practices by providing information and practical suggestions on energy conservation, water management, waste reduction, and sustainable transportation.

## Features

- Interactive chatbot interface
- Quick-access topic selection
- Keyword-based responses
- Responsive user interface
- Keyboard support for sending messages

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Structure

```text
Campus_Sustainability_Assistant/
├── index.html
├── style.css
├── script.js
└── README.md
```

## How to Run

1. Clone or download the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Select a topic or enter a question in the chat interface.

## Supported Topics

- Energy conservation
- Water conservation
- Waste management
- Sustainable transportation
- General sustainability awareness

## Internship Details

**Organization:** 1M1B (One Million for One Billion)  
**Program:** AI for Sustainability Virtual Internship  
**Duration:** May 2026 – June 2026

## Implementation

The chatbot uses predefined keyword-matching rules in JavaScript to identify supported topics and display relevant responses. It does not use an external AI API or machine learning model.
